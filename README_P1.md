# Проект 1: Анализ данных Крестьянской биржи труда

## Описание проекта
Скрипт предназначен для анализа выгрузки заявок с платформы «Крестьянская биржа труда».

## Данные (dataset.csv)
Файл содержит заявки с полями: id, date, region, category, title, budget_rub, status.

## Использование
``bash
chmod +x project1.sh
./project1.sh dataset.csv
``n
Скрипт использует `sqlite3` для импорта CSV во временную базу данных и выполняет три SQL-запроса.
